## 1. Faire le plateau

Commencez par assembler le plateau, toutes les pièces présentes dessus peuvent être déplacées. Un exemple de base est recommandé pour les premières parties.

## 2. Placer les jetons et les entrées

Mélangez et placez les jetons , face cahée, dans les batiments. Pas plus de 2 par bâtiment.
Choisissez ensuite 3 entrées autour du plateau et placez devant elles les pièces d'indication.

## 3. Choisir les héros

Choisissez les héros que vous voulez jouer. Ce jeu ce joue de 1 à 7 joueurs. Vous pouvez choisir de jouer autant de héros que vous voulez. A partir de 3 joueurs il n'est pas recommandé de jouer plusieurs héros par joueur.
Pour vous aider à choisir, vous pouvez consulter la page "Fiches Héros"

## 4. Démarrer la partie

Vous êtes prêts à commencer la partie. Placez les héros sur une case en bord de plateau qui n'est pas une case bâtiment. Vous pouvez choisir de commencer sur la même case ou de vous séparer. A vous d'être stratégique ou téméraire.
On vous laisse déterminer qui commence à jouer. Sachant que vous pouvez jouer dans l'ordre que vous voulez d'un tour à l'autre.
Les tours se déroulent de la manière suivante : d'abord les héros, ensuite les monstres déjà présents sur le plateau et enfin l'arrivée des nouveaux monstres.

## 5. Le tour des héros

Les joueurs jouents tour à tour en respactant le nombre d'action dont dispose leur héro.
Les joueurs doivent annoncer l'action avant de la faire.

Les actions sont :

- Se Déplacer
- Attaquer (Attaquer permet parfois de se déplacer)
- Soigner (sois-même ou un allié à condition d'être dans la même case, sauf spécificité perso)
- Retourner un jeton
- Utiliser un jeton
- Donner un jeton (En aucun cas un joueur peut prendre/voler le jeton d'un autre joueur. Sauf en cas de décès et à condition d'être sur la même case que le corps.)
- Ouvrir/Fermer une porte.

## 6. Le tour des monstres

Les monstres déjà sur le plateau bougent (voir fiches monstres) en direction de la dernière action.
Apparition des monstres à déterminer. (2D4 pour marcheur et coureur?)
Tous les 3 tours faire apparaître un nécromancien a une des entrées
Tous les 5 tours faire apparaître 2 brutes à 2 entrées différentes

## 7. Attaque des monstres

Les monstres attaquent un joueur lorsqu'ils sont sur la même case que ce dernier. Un monstre sur la même case qu'un joueur c'est une vie en moins (sauf spécificité monstre, voir fiches monstres).

## 8. Tour Nécromancien

Si un Nécromancien est sur le plateau il se déplace comme tous les autres monstres, en direction de la dernière action.
Une fois déplacé, il invoque 1D4 monstres sur sa case (ou case de l'action ?).

- 1 ou 4 = Feuille de boucher x2
- 2 = Couteau de cuisine
- 3 = Masse

## 10. Tuer le Bosse

Le bosse possède 3 vies représentées par les anneaux rouges. Le bosse perd une vie si il est attaqué avec une arme légendaire. Les joueurs possédant cet artefact ne peuvent s'en servir qu'une seule fois par tour et ça leur coute 2 actions.

## 11. L'XP

Chaque héros peut gagner un niveau tous les 5 points d'xp.

1 pt d'XP est gagné quand :

- Un monstre est tué (Feuille, couteau, nécromancien)
- Un héro est tué
- Un héro est soigné

2 pts d'XP sont gagnés quand :

- Un héro est réssucité
- Un jeton est retourné
- Une masse est tuée

1 Niveau est gagné quand :

- Le boss est tué
